# AYDO Skills public profile

[profile/README.md](profile/README.md) introduces the organization on its public
GitHub Overview. The profile describes our purpose, general workflow, focus areas,
and working principles.

## Contents

- `profile/README.md`: public introduction in Indonesian and a Mermaid workflow.
- `profile/assets/dashboard-header.svg`: shared visual style for the organization.

## Maintenance

Keep this repository public and its profile on the default branch. Keep the
introduction general: describe the approach without publishing repository
inventories, release details, implementation plans, operational records, or
installation commands. Review both text and assets before publication.

Preserve the established banner style when updating the profile. Check relative
image links, section links, and Mermaid rendering after changes.
